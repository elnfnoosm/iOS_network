# Surge 模块

在 Surge 里这类文件叫「模块」，扩展名一般是 .sgmodule。
不同软件叫法不同：Loon 叫插件、Surge 和 ShadowRocket 叫模块、Stash 叫覆写、QuantumultX 叫重写。

**这个目录下的文件由每日同步任务自动更新为上游最新版。**
不要在这里手工改文件，改了下次会被覆盖；要改就改根目录的 `sources.json`。
